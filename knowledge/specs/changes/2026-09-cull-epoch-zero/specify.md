# 清册 bill：两册整册归零、历元重启（焚烧沉淀仪式）
- Slug: 2026-09-cull-epoch-zero ｜ 日期: 2026-09-11 ｜ 本卷即**清册 bill**（自称位——C6 执法器凭此放行整袋删除；仪式法源 → 归属法 §4「卷宗清册执行」行）

## Why（为什么现在清）
项目主宣告：此刻册满改元——清册后开新历元，新历元专门做文档与知识的人工彻底清理，必须空袋起手。`specs/archive/` 是可清册存储不是永久档案馆；到期整册抹除的唯一合法路径就是一支独立清册 bill 走七步仪式。在册三袋皆为 2026-09 历元立法高峰期的产物，其论证早已经 ⑨⁺ 流入解读架，袋内剩下的本体是收据与会议记录。

## What changes（仪式终态，非怎么做）
- 两侧 `specs/archive/` 归零：框架区三袋整袋删除；镜像区空袋保持空。
- 解读架各篇指向已删案卷的篇脚回指整行删（行灭理存，论证不留堂）；全活面 date-slug 案名净空。
- 两区 archive README 回到空袋章程态；本 bill 自焚（末步整删自身目录，三区零残留）。
- 可观测终态：新 worker clone 本仓，全仓找不出这三袋与本 bill 存在过的任何痕迹，只剩解读架的因果与 current/ 的条文——如新仓起世。

## 验收标准（AC 账本 — 人话摘要；零条文零施工参数 → plan）
- **AC-1** 整册归零：框架区三袋 11 文件整袋删除、无拆件无择留；镜像区保持空袋；README 章程体存活。
- **AC-2** 再核闸过：本页 §再核表三案四栏齐；唯一缺口（四段案被拒方案栏）已先于删除补沉淀进解读架。
- **AC-3** 净面：活面 md 的 date-slug 案名逐处删除或转无编号散文；代码注释五处孤儿案名（其袋已随首期清册灭）同裁转散文；活面 `ADR-` 编号持续为零。
- **AC-4** 净账：两 archive README 册况行归空袋章程态，零案名零账目。
- **AC-5** 执法终绿：七闸 + check-diagrams + `mvn -B compile` 在「删除与自焚对 HEAD 可见」态全绿，终态 commit 后净工作区复跑仍绿。
- **AC-6** 自焚终态：`changes/` 与 `archive/` 零本 bill 残留；bill 本体曾于审议期入 HEAD（C6 自焚识别臂凭 HEAD 内容起效）。
- **AC-7** 历元重启：新历元零承接——不立新编号、不留账目、不留任何指向已删袋的回指；案名 date-slug 惯例不变。

## 约束
- 辖域 = 袋本体、两 README 册况行、活面标识符、解读架回指与补沉淀。`current/` 法卷零条款改动；`_template/` 零触；规则逻辑零触（触码仅注释措辞，零 Java 语义）。
- 本卷是清册 bill：**不折叠、不落 §裁决记录**（执行非裁决事件）；两门放行凭据 = 会话中项目主明示 + 审议期 diff 可见的本页再核表；自焚是合格终态。
- 次序刚性：补沉淀先于删除；净面、净账先于自焚；终闸在「删除+自焚对 HEAD 可见」态跑。

## 不做（范围边界）
- 不做新历元的「文档与知识人工彻底清理」本体——本 bill 只交空册，清理是后续各案。
- 不删 theory-map 账本行（只删指向已灭袋的回指句）；不动 glossary（现行词条皆无案名）。
- 不因「回指消失」改写解读架论证正文——行灭理存，论证本就不依赖案卷立身。
- 执法器 C6 一字不动（装置已配平清册制，随探测器演化另案）。
