# 用法规范法卷：批量写操作（框架法 · 严格件）

> **身份**：本卷规范批量 Command/Handler 形态；修卷走 `../../changes/`。docs 同题篇（`how-to/batch-operations.md`）为宽松件，冲突以本卷为准。
> **机器对账**：C1/C3/C4 扫本卷。开册法案：`2026-09-howto-codification`。

## 条款

| # | SHALL | 取证 | 背书 |
|---|---|---|---|
| BW-1 | 批量写 = 单一 Command 携带 ID 集合 + 单一 Handler 整批处理；禁止为批量另发明新层 | `how-to/batch-operations.md` 结构段入法 | — |
| BW-2 | 事务边界在 Handler 单事务内：整批**要么全部成功要么全部回滚**（强一致默认）；部分成功语义禁止隐式出现，如需须另案修法 | 原篇需求 2 入法 | — |
| BW-3 | 分片职责在调用方：单次执行分片建议 ≤500 条/批（建议值为上限参考，非机械判据）；Handler 禁止自动拆分、禁止嵌套开启新事务 | 原篇「不要跨事务原子性地嵌套调用；调用方负责切分，≤500 条/批」入法 | — |
| BW-4 | 批量内每条目标的处理仍走聚合行为（WC-2/WC-3），禁止绕聚合直改表 | WC-2/WC-3 互指 | ArchUnit |
