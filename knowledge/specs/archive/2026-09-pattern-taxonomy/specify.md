# 增设「摆架法卷」并物理建架：模式法卷十摊入路径、四宗条款搬家、空穴立牌
- Slug: 2026-09-pattern-taxonomy ｜ 日期: 2026-09-11

## Why（为什么现在改）
`current/patterns/` 十五卷混放、无摊地图：新卷落哪凭口头默契，卷籍全仓无权威住所。2026-09-11 会话裁出十摊地图（v4）并要求：理解成文为法、摊进文件路径（路径即户口）、空穴摊预建立牌、四宗条款搬家本期直接执行——登记式摆架不足以承载，须迁都。

## What changes（做什么，非怎么做）
- patterns/ 下建**十个摊子目录**（meta/diplomacy/building-block/chain/collaboration/boundary/data-access/security/discipline/deploy-ops），现存十五卷按摊 git mv 入册；**目录路径就是卷籍名册**，"ls 即户口"，摊卡不再抄卷列表。摊目录名一律单数、概念名、无缩写。
- 新增第二卷元法**摆架法卷**（住 meta/）：十张摊卡（验证问句／管什么／界线／摊路径／空穴指针）成文为法条；十摊摊头各立一块**牌面 README**（一句问＋指针，零条款零形状；空穴摊有牌无肉）。
- 四宗搬家本期动肉：分层条款（WC-1、CC-3＋结构映射表）→ 新卷《分层法卷》；SQL 铁律（禁令卷 §6 整节正身）→ 新卷《持久化语句法卷》；安全孤条（CC-8）→ 新卷《安全链法卷》；契约构成与分页两条（CC-7、CC-9）→ 入既有卷（聚合构建宪、读用例链）。原条款号**保号互指**（判例句式=RC-3），一字不改只搬家。
- 章程与元法同步：specs/README（19 卷口径、路径形状）、伞 README 树、归属法卷 §2 表增行；全仓入站指针（实测 112 行）改道。
- 可观测差异：任何人看目录树即见十摊；携新卷来，摊卡问句裁归架；空穴摊的牌上写明"洞在此、证据为何"。

## 约束
- 框架区（伞内）法；镜像区零触；Java 代码零触（AGENTS.md 与 .agents/README 的文档路径除外）。
- 搬家范围**封死在四宗**：除此之外的条款一字不动；契约"版本演化法"（空穴 3-1）是造新法非搬家，不入本案。
- 执法器零触（P-7）；名册对账=评审项＋目录现实，无新自动闸。
- 条款号零重排：搬家用"保号互指"（先例 RC-3 句式），废号才触"废号零容忍"红线。
- 教学中立：摊卡例子用普通业务词、置于代码围栏与反引号之外；目录名纯英文 kebab。
- git mv 与 commit 由人工执行（禁令卷 PB-G1 在位：Agent 只备命令与清单）。

## 不做（范围边界）
- 不重排任何条款编号、不改任何未点名条款的文字
- 不为空穴摊造法（牌面之外零内容；第一卷落地销穴属后案）
- 不新增机器闸、不碰豁免白名单
- 不动 modules/ 八卷的条款（仅其指向 patterns 的链接改道）
- 镜像区 sample-application/specs 不预建摊目录（其摆架等框架架跑通后另案）
