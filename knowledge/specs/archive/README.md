# knowledge/specs/archive/ —— 已归档案卷（案卷封存袋，到期整册归零）

**册况**：本袋在用。早前批次的案卷已全部清册归零，此后每完成一案折叠迁入一份。袋内案卷清单不写在本页：README 常驻的是章程，不驻账目。

**入袋规矩**：折叠完成的案卷**整目录**迁入，命名 `<YYYY-MM-kebab>/`；不拆件、不留守，一名一袋，袋名望文生义。案卷形状随立案当天的模板，在位不回改。在位只进不改，连错字也不改：袋里存的就是当时的过程记录。要推翻旧案，就新立一案接管，旧袋即成历史。拆件删、择留删、没有清册 bill 授权的删除，一律红（C6 清册臂）。

**入档前义务**：入袋前先过两道闸。其一，瘦身闸：两门收据与各裁决条目已全部落进 specify 的 §裁决记录（形状 → 归属法 §4 瘦身闸行）。其二，⑨⁺ 论证沉淀：裁决的沉淀论证（现行版）已复写进 `docs/explanation/` 同题篇，篇脚回指 `→ 案卷 <date-slug> §裁决记录（决策快照）`；这条回指只在案卷还住本袋期间有效，清册时整行随案卷删除，论证留在解读架。两道闸的条文与豁免 → [归属法](../current/patterns/attribution-law.md) §4 强制同步表。

**终态 = 清册归零**：本袋连同镜像区 archive 是**可清册存储**，不是永久档案馆。发布节点由一支独立的清册 bill 整袋彻底抹除：案卷本体、README 账行、活面残留的案名标识符全部删净；审计链阅后即焚，**不留账**。git 历史不算知识住所，知识也不以本区为存在依赖：因果全文常驻 `docs/explanation/`，条文现行文本常驻 `specs/current/`。前置条件：自足判据先过；逐案再核表随 bill 递交，缺案不批。清册 bill 不折叠，末步整删自身目录（自焚），条款全文在归属法 §4「卷宗清册执行」行。另注：`ADR-NNNN` 旧编号在活面零容忍属常设 C6 执法，不待清册触发。制度原理 → [knowledge-system.md](../../docs/explanation/knowledge-system.md)「清册制」节。机器执法：check-docs C6 两臂。
