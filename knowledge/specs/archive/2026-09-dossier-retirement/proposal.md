# 卷宗清册制——specs/archive/ 与 decisions/ 到期彻底抹除，册净如新、改元重启
- Slug: 2026-09-dossier-retirement · 日期: 2026-09-09 · 关联 ADR: ADR-0037（折叠时新立）

## Why（为什么现在改）
- 现状一句：现行法把 `decisions/` 与 `specs/archive/`（含镜像区）钉成**永久冻库**（正文永不回改、只进不改），「清空」在法律上无路——物理删除 = 违规（C6 红 + 违归属法 §1）。
- 项目主裁定（2026-09-09 两进裁定）：① 本体要**能删**；② 且要**删得干净**——相关知识与前因后果**完整沉淀之后**，本体、账行、活面一切具体标识符连痕迹一并抹除。每个发布节点，项目应像**从空目录启动的新仓库**：脚手架 + 开源双重身份决定两册必须空着交出去，让下游开发者写自己的第一案。
- 前提成熟度：ADR 侧 36 案论证已全量入解读架（2026-09-09 迁移满覆盖）；archive 侧条文已住 current/（折叠闸保证）。**残余缺口**：瘦身闸晚于前几案生效，早期案卷 proposal 可能夹带未走 ADR→explanation 管道的论证；且「被拒方案之理由」这类前因后果至今只存于两册——本法立「自足判据」，强制补齐后才许抹（→ delta §4 仪式①②）。
- 收益一句：知识自足于 `docs/explanation/` + `specs/current/`；清册归零不是丢东西，是**兑现沉淀**；git 历史不再是任何知识层的存在依赖（「法不考古」）。

## What changes（行为宣称，映射 delta）
- **ADDED** §1「卷宗清册制」注：两册 = **可清册存储**。清册 = 本体整袋删除 + README 账行同裁（README 常驻的是**章程**，不是账目）+ 活面全部具体标识符（`ADR-NNNN` 编号、date-slug 案名、页脚快照账行）净空改写。**清册即改元**：编号历元归零，新案从 `ADR-0001` 重起。存活件仅两项：explanation 中的前因后果全文（含被拒方案之拒因，按自足判据逐案核）+ current/ 条文现行文本。
- **ADDED** §4「卷宗清册执行」行：七步仪式，SHALL 附**逐案再核表**（每案四栏：立因 / 取舍 / 被拒方案及拒因 / 生效边界，去向 = 解读篇某节，或本行判「纯史件，随灭」），**表缺案、沉淀缺节则批准门不得通过**；末步空册自洽由 C6 清册臂机器核验。
- **MODIFIED** §1 三类件分家注尾部与 §2 两行：「封存/冻库」措辞改「冻结在位、到期归零」；一切「退役后锚账行」设计删除——净面之后无处可锚，解读篇自足即为归宿。
- **MODIFIED** specs/README 与镜像 README 的 archive 行；archive/README 重写为**纯章程**（在库清单是工作表非存活件，清册时刻随本体一并归零）。
- **工具法**：C6 两臂——**冻结臂**（在位涂改 = 红，零容忍不变）+ **清册臂**（空册自洽：区空 ⇒ 全活面不得残留该期具体标识符，正则 `ADR-\d{4}`（占位形 `ADR-NNNN` 除外）与 date-slug 形；区不空 ⇒ 本体整删仅出自清册 bill 的 diff 放行）。
- 连带（非条款）：ADR-0037 新立、knowledge-system.md 清册节（⑦⁺ 自我适用）、glossary 词条、new-bill skill 措辞、伞 README 复述行、图标签重渲。

## 不做（范围边界）
- **本案不执行任何清册**：九案 + 36 案原样在库。第一次清册在下一发布节点由独立小 bill 照七步仪式执行——**该清册 bill 自身也是案卷，下期清册时随区一并归零**（递归洁净：仪式产物不豁免于仪式）。
- 不涉 git 历史的发布形态（squash / 孤儿新仓 / 全史随发）：那是**发行决定**不是知识居住位；本法立场一句「法不考古」——任何知识层不得以 git 历史为存在依赖，历史怎么发由项目主逐版自决。
- 不回改历史案卷（在位不改）：pg-native-shape 漏勾（2026-09-09 普查发现，实为完工）在首期清册再核表中一笔处置，物不回改。
- 不规定清册周期：触发 = 发布节点 / 项目主宣告；节奏是习惯，不是法。

## 待项目主裁决的两问
1. **改元重启**：每次清册后 ADR 编号从 `ADR-0001` 重新起算（历元内唯一；跨历元同号不同案，法不救济考古歧义）——确认？（另一档：编号永不断增——但号本身即上一世痕迹，与净面相悖，不推荐。）
2. **页脚快照账行的寿命**：解读篇 `ADR-NNN（决策快照）` 回指在清册时刻**整行删除**（行灭理存——论证早已在正文与解读架）——确认？
