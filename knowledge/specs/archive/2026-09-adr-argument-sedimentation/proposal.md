# 架构决策的论证正文改由解读架承载（ADR 降为事件记录＋授权收据）
- Slug: 2026-09-adr-argument-sedimentation ｜ 日期: 2026-09-09 ｜ 关联 ADR: 无（分家决策当时仅案卷留痕未立判例，本案自记新账）

**表决行**：2026-09-09 项目主批准本案——Q1 分层复写、Q2「仍成立且指导读法」判据、Q3 强制回指，均照推荐批准；追加行文裁决：**行文以目录名为主词，旧指代词（案卷/卷宗）仅括注辅助**。→ 详情与论证正文快照：折叠时立 `ADR-0036`（本案 ⑦⁺ 自指履行：现行版复写入 `docs/explanation/knowledge-system.md`）。

## Why（为什么现在改）

现行归属法 §2「架构决策（论证）」行把论证正文的 canonical home 钉在 `decisions/`、他处（含 docs/explanation）只准指针禁复写。这与知识分类的本性冲突：**ADR 是决策事件的记录与决策当时的思考（时间锚定的历史证据），不是最终的知识沉淀**；"现行法为什么长这样"属于活的解读，若只准指针回 ADR，等于让沉淀结果反向引用过程记录——知识与收据错位。现状后果：解读架对重大论证永远只能挂指针，读者要懂"为什么"必须考古卷宗；本仓分层设计 5 篇的纵深论证因此先天残缺。

## What changes（改什么行为，非如何实现）

- **MODIFIED** §2「架构决策（论证）」行：canonical home 语义一分为二——决策事件＋当时思考＋Confirmation（授权收据）仍住 `decisions/`（冻结、append-only、C6 执法不变）；**论证的现行版（沉淀道理）canonical 迁至 `docs/explanation/`，折叠时刻（⑦⁺）复写入同题散文成为强制同步义务**（不再是「允许就近重述」的可选项）。
- **MODIFIED** §1 分家注：补一层——「案卷不双写 ADR 论证」禁令原样保留（那治的是法区内两处副本）；新增区分「卷宗（冻结收据）↔ 解读（活的现行）」非双写而是**源与流**：收据永不改，现行随法演化，二者允许论证重叠、时效语义不同。
- **ADDED** §4 强制同步表新行：法案折叠时，该案所立/所改 ADR 的沉淀论证必须同 PR 复写进对应解读篇（无同题篇则立篇，走登记法）；theory-map 账本行照旧。
- 图的 ⑦⁺ 边标签、glossary 三词条（一次设计/论证沉淀/ADR）、README §2.1 锚表随折叠履行文档同步义务。

## 不做（范围边界）

- 不废止 decisions/ 区、不改 append-only/C6/supersede 链、不动 Confirmation 必填——ADR 仍是授权唯一凭证与判例先行回引对象；
- **不回溯考古**：存量 49 篇 ADR 不强制补写解读（触发式随动：哪个专题的解读篇下次被改写/新法案涉及，哪个顺位收编）；
- 不动镜像区（sample-application/specs 只援引框架区，自动跟法）；
- 不引入自动抽取工具（复写是人/AI 在折叠时的义务动作，机械化留待攒案例）。
