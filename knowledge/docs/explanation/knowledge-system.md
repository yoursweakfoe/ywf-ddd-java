# 知识系统的自我解读（两类件：案卷含裁决、道理）

> 本页解释这套知识体系为什么长成 `docs/`、`specs/` 两区加 `.agents/` 工作台。裁决历史上曾单设一个独立的判例区（ADR），2026-09 判例归卷案撤销了它，并入案卷。归属判据一句话：**这句话能机械化执行吗？能 → 法卷；不能 → 这里。** 制度条文本体在 [归属法卷](../../specs/current/patterns/attribution-law.md)，本页只讲条文背后的为什么。

## 一个决策事实的两份分身

一个决策落地，会留下两类时间属性完全不同的事实。把它们混进同一个文件，或把一个裁决拆成两处记录，都是本仓的历史病灶：案卷与 ADR 曾近乎同文双写，裁决表与论证互相抄录。现行制度按**时间属性**分家：

| 分身 | 居所 | 回答的问题 | 生死 |
|---|---|---|---|
| **立法过程件（含裁决位）** | 四件案卷 specify/plan/tasks/implement，住 `specs/changes/`，折叠后整袋迁入 `specs/archive/`。旧案是三件套形状；判例归卷案起，specify 内含 §裁决记录一节 | 当初为什么要改这部法（specify 前段）；当时怎么定的、谁在何时授权、supersede 了谁（specify §裁决记录：门次收据、裁定与当时理由、Confirmation）；改哪些法、怎么做（plan）；活怎么派（tasks）；干成没有、凭什么（implement 账） | 折叠即使命终；入档后在位只进不改；到期整册删除，见下文"清册制"一节 |
| **知识沉淀件** | `docs/explanation/`（含 theory-map 账本） | **今天**这部法为什么长这样 | 活的地图，随法演化，烂了直接修 |

两者不算重复记录，关系是源与流：案卷 §裁决记录证明知识有合法出处，授权可审计；`docs/explanation/` 让知识自立可读，理解"为什么"不必翻旧卷宗。这层区分在 2026-09 之前不存在。旧制把论证正文钉死在 ADR 区，解读架只准挂指针，等于让读者为了理解一条现行规范，去翻一场已结束辩论的会议记录。论证沉淀案把这个方向倒转回来。判例归卷案再进一步：裁决与过程同属"当时"的事实，时间属性相同，分住独立区正是双写病根；于是判决并入案卷 §裁决记录，与过程件同件封存、同袋销毁，不允许只删一边。

## 过程件内部为什么再分四段

两类件分家（旧称三类件分家）回答了"事实归哪个区"，但 `changes/` 案卷内部一度仍是旧三件套合居：**「怎么做」没有正典位**，被迫寄养在别的文件里。病灶在 p6spy 案上活体自证（该审议袋于四段制生效后按项目主令撤下，修整文档规划后重新立案；病灶记录仍真）：机制条款（runtime scope、版本 pin 坐标）混进 spec-delta 的 SHALL，设计事实冒充行为事实；spy.properties 整串键值塞进 tasks 条项，施工图混进验收清单；而施工取证与验收对账根本没有居所。

四段制（specify → plan → tasks → implement）按**书写时刻的时间属性**给每类文字一个固定位置。判据与两类件分家同源，落笔时问这句属于哪个时刻：**事实之前**的问题与验收写进 specify 前段；**门次拍板**的裁决快照（裁定、当时理由、授权收据、supersede 宣告）写进 specify §裁决记录；**未来态**的做法与条文（修卷 delta）写进 plan；**动作序**写进 tasks；**事实之后**的勾验与证据写进 implement。§裁决记录这个居所由判例归卷案确立：裁决与问题同属"当时"，不再拆进两个文件。单一抄本执法：条文正文在案卷内唯一住 plan，specify 只登 AC-n 人话摘要。这是宽严双份制在案卷内部的镜像，权威结构与伞区同构。

批准门同步从"判例补丁"升为常制：Specify 门 → Plan 门，**每案两停、不论大小，法条不写豁免条款**。"想不停门"是会话中项目主的明示意图，属人机协作的对话层；写进条文反而会腐蚀规则刚性。这就是"法条刚性、出口在对话"，项目主立此品味。

四段之外不再设第五件、第六件，同样是裁过的：**不立 constitution.md 独立件**——本店宪法 = 根 `AGENTS.md` 九条加 `specs/current/` 法卷，归属法 §1 已钉死，再造一份"宪法文件"就是两份宪法，两份必有一处先烂；**不立 clarify.md 独立件**——澄清是拍板前的提问清单，天然住 specify 的"待裁问句"节，独立成件等于把一次门内往返拆成两处维护，问与答隔件相望。底下还是那条判据：一件对应一个书写时刻，多一格就多一处腐烂位。

## 为什么"当时思考"不能冒充"现行道理"

决策时的论证带时间戳：它引用当时的备选、当时的版本、当时的无知。法律生效后，理由分成两半。一部分**继续成立并指导读法**，这是知识，复写进 `docs/explanation/`，随法维护。另一部分只在当时情境成立，这是历史证据，留在案卷 §裁决记录当化石，永不回改，也永不更新。划界判据一句话：**法生效后这条理由是否仍成立且指导读法。**

推论：`docs/explanation/` 是这套体系里**唯一允许对"为什么"做版本升级的载体**。法改了，解读篇跟着改写不算篡改历史，因为历史不住这里。这也是 D2 驱动关系图上「设计（修改与决策构成一次设计）驱动文档修改」这条边的完整含义：每次 ⑨⁺ 折叠，论证的现行版随案进入解读架。复写义务的**机械化曾议而暂缓**：折叠当刻由人或 AI 就地成文。"哪段论证值得沉淀"尚无机器可判的判据，攒够案例再议，不预建自动抽取工具。

## 行文法：为什么叙述制度一律用目录名当主语

全架文档指称一个知识区时，**主语必须是目录名**，例如 `decisions/`、`specs/archive/`、`docs/explanation/`。案卷、卷宗、判例架、解读架这类旧行话，只准出现在括注里当辅助记忆位。这是 2026-09 项目主裁决，论证沉淀案同案追加。理由：读者的心智地图必须锚在磁盘上真实存在的目录树上。黑话会随制度演化失真，「判例卷宗」就曾指论证的唯一权威住所，如今论证住 `docs/explanation/`。目录名跟着树走，永不与地形脱节。对 AI 协作者这条更是硬需求：它按路径读写，不按比喻读写。本节自身即照此法写成。

## 为什么 process 区（`.agents/`）不入伞

方法（skill）是**可弃工具**的说明书：工具栈可换，知识与契约不可弃。所以流程住 `.agents/`，那是各工具原生扫描路径钉死的位置；法律与描述住 `knowledge/`，同仓伞下原子同步。法不落在方法树里，skill 内零法条零模板。否则弃用一个工具时，法律会跟着一起消失。

## 为什么一切改法走 `changes/`，连本页讲的制度自身也不例外

归属法是宪法，但「元法亦是法」：它把自己也交给同一套立法程序管辖。这样体系里没有"不可被程序修改的神圣文本"，只有三份各得其所的记录：此刻有效的条文、可查的授权史、可续写的道理。

## 清册制：两册为什么敢到期彻底归零

**立因**：本仓有双重身份，既是产品也是脚手架。开源交付物里塞着几十个"上一世会议记录"性质的 ADR 与案卷，等于把成长痕迹当出厂垃圾。项目主要求的发布形态是：**每个发布节点都像从空目录启动的新仓库**。两册（两侧 `specs/archive/`，含镜像区）到期时目录还在、内容为空，让下游写自己的第一案。旧制是永久冻库加 C6 零容忍，没有合法的删除路径，终局意图在法上走不通。

**为什么敢删**：真正值钱的只有两类活物，都不住册袋。条文现行文本住 `specs/current/`，由折叠闸保证，delta 只是草案副本。因果道理住 `docs/explanation/`，由 ⑨⁺ 强制复写保证。册袋里的本体本质是仪式用品：收据与会议记录。

**被拒方案及拒因**：本节即自足判据的自我执行。将来任何人重提这些方案，答案在此，不必翻历史。

- **账行永驻案**（本案 v1 草案）：案卷可删，README 索引行永留，"身可死而账不可失"，删行等于伪造记录。项目主否决。账行列出"本仓曾立过三十六案"，本身就是上一世的痕迹，与"如新仓启动"的发布态直接矛盾；而且留账必然衍生"回指锚账行"的二级复杂度。
- **git 历史兜底案**：只删工作树文件，git 历史永在，追溯有路。否决理由两条。开源发行随时可能 squash 或以孤儿仓库起仓，历史兜底不可靠。更根本的是：任何知识若"其实 git log 里还有"，就是沉淀未完成，不该拿历史当借口。知识的权威面永远在工作树，法不考古。
- **维持冻库案**：承认终局删不掉，开源时整仓剔除历史。否决：等于把治理制度输给发布脚本，清册只能在法律之内发生。
- **编号永不断增案**：清册改元后仍续用 0038、0039 这类编号。否决：跨世连续的编号序列本身就是"上一世存在过"的化石，与净面要求相悖。所以**清册即改元**：案册归零即重启计数，编号只在历元内唯一；同号歧义法不救济，也无从救济，因为面上已无痕迹。

**生效边界**：`changes/` 在途案卷永远完整，清册不碰正在审议的立法。瘦身闸、⑨⁺、supersede 案卷链全部原样有效；清册只在链条末端加一道"归零前验沉淀"。防偷删靠 C6 两臂：案卷在位被涂改则红牌；整袋删除仅在自称"清册 bill"的在途案卷下放行，且必须**整册清空**，禁拆件择留；`ADR-\d{4}` 属常设零容忍，编号制已废，残留即幽灵，不待册空；册一空，全活面该期标识符（date-slug 案名、页脚快照账行）残留即为红。合法的删除终态是：案卷本体与它的账行一起消失，活面标识符清零。执行清册的 bill 自身也是案卷，下期归零：仪式产物不豁免于仪式。
