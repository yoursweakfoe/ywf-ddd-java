# ADR-0037 卷宗清册制：两册到期彻底归零，不留痕迹，改元重启

**Status**: Accepted（2026-09-09，用户裁决：批准 `2026-09-dossier-retirement` 全案——Q1 改元重启（历元后编号自 `ADR-0001` 重起）确认 / Q2 解读篇页脚快照账行清册时整行删除确认；裁定基调"相关知识和前因后果都被完整沉淀，对应的 ADR 内容和 archive 内容连存在的一切痕迹也一并清理，每到一个时间点项目都像清爽从头启动"）
**关联法案**: `2026-09-dossier-retirement`（归属法 §1 三类件分家注改文 + 新设「卷宗清册制」注 / §2 架构决策+过程事实两行改文 / §4 新设「卷宗清册执行」行；specs 宪章与镜像区 archive 行改文；archive/README 章程重写；C6 两臂工具法）
**部分冲正**: 本案 v1 草案的「身可死而账不可失」（README 账行永驻 + 限定名退役后锚账行）设计经项目主二进裁定**否决**——账行本身即上一世痕迹，与"发布态如新仓"相悖；现行版改为彻底抹除制（过程件内草案原文按在位不改留存，随首期清册归零）。`2026-09-adr-argument-sedimentation`（ADR-0036）所立 ⑦⁺ 复写义务**保留并加重**——自足判据要求前因后果全文入解读架，方许抹除。

## Context and Problem Statement

归属法把 `decisions/` 与 `specs/archive/`（含镜像区）钉成永久冻库：正文永不回改、只进不改、无合法删除路径。项目主终局裁定与此冲突——脚手架 + 开源双重身份要求**每个发布节点交出的仓库像新启动的空白工程**：两册目录存在但为空，供下游开发者写自己的第一案。git 历史不能充当兜底：发行随时可能 squash 或孤儿起新仓，且"去 git log 里考古"本身违背"清爽如新"的体验承诺。任何知识层若依赖过程件本体存活，就是沉淀未完成，不是过程件该永生的理由。

## Decision Outcome

1. **两册 = 可清册存储**：清册 = 本体整袋删除（whole-directory/whole-file，禁拆件择留）+ README 账行同裁（README 只常驻章程段）+ 活面**具体标识符净空**（`ADR-NNNN` 编号、date-slug 案名、解读篇页脚快照账行整行删除——行灭理存；法卷"某某案 立"式生效注转无编号散文）。
2. **自足判据（先验门槛）**：每案四栏因果——立因 / 取舍 / **被拒方案及其拒因** / 生效边界——须已完整住进 `docs/explanation/` 或 current/ 条文；判据一句话：**从未见过卷宗的读者能从解读架复述该案全部因果**。再核表随清册 bill 递交，缺案缺栏则批准门不得通过。
3. **清册即改元**：两册归零、编号历元重启（`ADR-0001` 起，历元内唯一；跨历元同号歧义法不救济）。
4. **法不考古**：git 历史不是存活件，任何知识不得以历史为存在依赖；历史发布形态（全史/squash/新仓）是发行决定，本案不立法。
5. **仪式产物不豁免于仪式**：执行清册的 bill 自身也是案卷，下期清册随区归零。
6. **机器执法 C6 两臂**：冻结臂=三区本体在位涂改零容忍（decisions 正文按宪章豁免 Status 行 1:1 对替——补齐闸与既载章程长期错位）；清册臂=(a) 本体整删仅清册 bill 在途放行且删后该册必须归零，(b) 空册自洽——册空则活面该期标识符残留为零。

## Consequences

- 正向：仓库在任一发布节点自洽如新仓；解读架被迫成为**唯一因果权威**（沉淀质量由删除门槛倒逼，杜绝"反正卷宗里还有"的半吊子复写）；下游用户永远面对空册 + 满知识，无幽灵引用。
- 代价：解读架新增"被拒方案之拒因"类内容（此前只存 proposal），每案清册前须逐栏补核；每次清册是一次多文件改写工程（净面），非单纯 rm -r；历元编号歧义（两世同号）无法内自证——接受，因为净面后活面无从也无需知道上一世存在。
- 边界：本制不适用于 `changes/` 审议区（在途案卷永远完整）；瘦身闸、⑦⁺、supersede 诸旧制原样有效，清册只在末端加一道"归零前验沉淀"。
- 验证：纯宣称文本 + 工具法案（不触 Java 行为）。取证 = `check-docs.ps1` C6 两臂五例演练输出（本案卷 tasks 附注）+ 折叠后七闸全绿；本案即时履行 ⑦⁺——现行版论证复写于 [knowledge-system.md](../docs/explanation/knowledge-system.md)「清册制」节，页脚回指本快照。
